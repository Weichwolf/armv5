# ISA and implementation coverage

A4 and the published A5 memory-control increments execute the operations below
through prepared LLVM images. This is **not** complete ARMv5TEJ qualification.
The ARM926 memory system and remaining CP15 effects are open.
Tests are independently authored programs, run through the public interface with
installed images. Rejected preparation cannot produce an installed image and is
checked through `Core::lower`; no private decoder or alternate executor is used.

|---|---|
| ARM AND/EOR/SUB/RSB/ADD/ADC/SBC/RSC/TST/TEQ/CMP/CMN/ORR/MOV/BIC/MVN | Direct SSA; `test/isa/preparation.cpp` checks all 16 operations across signed/unsigned numeric boundaries, carry/borrow/overflow, Q/V preservation, complete visible registers |
| Operand 2 and shifts | Immediate/rotated-immediate, immediate shift and register-controlled LSL/LSR/ASR/ROR, RRX; counts 0/1/31/32/33/255/256, incoming carry, constant rotation; further encoding combinations remain to qualify |
| Predication | All 15 ordinary conditions against all 16 NZCV combinations; false memory predicates have no access/writeback effects |
| B/BL, BX/BLX register, PC | Known successors linked directly; forward ARM BL leaf bodies use caller-specific SSA return edges with checked LR/loaded-PC and cold modified-target exits; ARM destinations and returns exercised by K4; Thumb BX/BLX register, ARM BLX immediate (including interworking state changes) and interrupted Thumb BL/BLX pairs exercised by installed fixtures; interior continuations and unknown fallthrough checked |
| LDR/STR/LDRB/STRB | Immediate/scaled register offsets, indexing and writeback implemented; public tests cover pre/post up/down access, byte/word, legacy unaligned word rotation, both endiannesses, fixed and dynamic memory paths, region-end/underflow/narrow-region/wrap bounds and complete fault prefixes; K4/K5 check complete memory output |
| LDRH/STRH/LDRSB/LDRSH/LDRD/STRD | Immediate/register addressing implemented, signed extension and pairs; fixtures cover signed byte/halfword and doubleword loads/stores in both byte orders. Unpredictable alignment and operand combinations explicitly refuse; exhaustive addressing combinations remain open |
| LDM/STM | Ordinary-bank IA/IB/DA/DB implemented, ordered transfers and writeback; independent stack push/pop fixtures and K4 returns; user-bank forms independently checked in all five exception modes, plus LDM^ exception return and old-bank writeback |
| SWP/SWPB | Uncached forms use one atomic I/O callback or one owner RAM transaction; cached forms use the DCache path below. Byte/word and legacy alignment implemented, both byte orders checked; remaining architectural abort-ordering qualification is open |
| CP15 MRC and register-only MCR | `test/isa/system.cpp` independently checks reset ID aliases/cache geometry, control/TTBR/domain/fault/context/lockdown reads, software writes to DFSR/IFSR/FAR/context ID, NZCV-only MRC R15, predication and User-mode Undefined. | CP15 A/L4/V controls | `test/isa/control.cpp` checks alignment faults before any access/writeback in all seven modes, ARM/Thumb, both byte orders and fixed/dynamic memory, including single/extra/double/multiple/SWP transfers, signed bytes, false predicates and preserved IFSR. LDR/LDM/Thumb POP honor L4 while BX/BLX keep interworking; yielding loads and LDM^ SPSR returns are checked in `test/core/returns.cpp`. `test/core/control.cpp` checks high SWI/UDF/BKPT/Data Abort/IRQ/FIQ vectors from ARM/Thumb, exact banks/status/cycles, missing high-vector declarations, snapshots and an alignment fault after a completed counted-loop turn |
| External data-abort status with MMU disabled | `test/isa/aborts.cpp` independently checks DFSR=8 and original/burst FAR for ARM/Thumb loads, stores, SWP/SWPB, byte/signed-byte/halfword/signed-halfword forms, LDRD/STRD and multiple transfers. All seven modes, both byte orders, fixed/dynamic paths, missing/denied storage, faults before/after 1KB boundaries and the top of the address space; exact partial memory/register state, no writeback/retirement, guest MRC readback and snapshots. Refusing callbacks preserve fault registers and retain host-fault diagnostics. Existing range and partial-code-write abort fixtures retain their checks and now assert fault-register effects |
| MMU/FCSE translation and faults | `test/isa/mmu.cpp` checks sections in all seven modes, both byte orders and fixed/dynamic layouts; coarse/fine large/small/tiny pages; an independent domain/AP/S/R read/write/SWP privilege truth table; LDRT/STRT User permission; FCSE low/high addresses and alignment priority; physical ITCM/DTCM selection after translation. Exact data/prefetch translation/domain/permission/walk-external status, original virtual PC/LR, modified FAR including A=0 byte offsets, preserved other fault registers, partial multiple-transfer state/base restoration and physical burst FAR. Faulting unknown instruction destinations precede undeclared-code diagnostics; valid undeclared aliases still refuse |
| Unified TLB and lockdown | `test/core/mmu.cpp` checks all c8 c5/c6/c7 aliases, ordinary and locked fills, victim wrap, shared instruction/data hits, stale page-table mappings across reinstall, invalidate-all preserving locks, single-MVA removing locks, mixed subpage permission retention/refill, hidden-TLB and pending-transition snapshot replay. | DCache and c7/c9 maintenance | `test/isa/cache.cpp` checks all M/C and page C/B policies, read allocation/write misses, WT/WB byte/half/signed/word/unaligned/double/multiple/SWP/SWPB forms, all seven ARM modes, Thumb transfers, both byte orders and fixed/dynamic layouts. Independent complete register/RAM expectations, dirty-half visibility, false maintenance predicates, AP checks on hits and LDRT/STRT are included. Cleaned code aliases revoke through declared variants or fail explicitly; partial failed code writebacks preserve bus/fault-register prefixes and pending-transition snapshots |
| Absent external coprocessors and illegal CP15 classes | MRC/MCR, CDP, LDC/STC and MCRR/MRRC to coprocessors 0–13 take precise Undefined without transferring data. ARMv5 MRC2/MCR2/CDP2/LDC2/STC2 execute unconditionally and take the same exception. CP15 permits privileged ordinary MRC/MCR only; other legal ARMv5 classes take Undefined. `test/isa/coprocessor.cpp` checks every external number and each class, all seven modes, both byte orders and fixed/dynamic layouts: exact ADDS SSA prefix, true/false predicates, NZCVQ, FIQ/exception banks, LR/SPSR/vector, return, unchanged complete RAM/fault registers and zero I/O calls even for unmapped/unaligned memory operands. Long/indexed/unindexed/literal memory forms and MRC R15 are included. ARMv6 MCRR2/MRRC2 and malformed extension encodings still refuse preparation. CP14 remains open |
| TCM storage and CP15 assumptions | `test/isa/tcm.cpp` checks overlay data routing, both byte orders, fixed/bus-only/dynamic layouts, top/zero bases, all nine legal TCM sizes, SWP and instruction-source invalidation. `test/core/tcm.cpp` checks guest MCR context changes and state-selected alternatives, exact bounds, pending-transfer snapshots, TTBR/PID masks, TCM disable/relocation/re-enable, boundary-split executable validation and invalid writes. `test/core/system.cpp` checks storage geometry/presence, context-specific install, profile snapshots and artifact identity |
| MRS/MSR | CPSR/SPSR reads and byte-selected writes, privilege masks and dynamic mode validation; all seven modes switch prepared units. All five SPSRs roundtrip and restore NZCVQ/mode through MOVS PC and LDM^; invalid User/System SPSR forms refuse preparation |
| MUL/MLA/MULS/MLAS | Direct SSA multiplication and accumulate modulo 2^32; independent edge products, NZ updates and CVQ preservation; K6 FIR. Long/DSP forms covered below |
| UMULL/UMLAL/SMULL/SMLAL | All signed/unsigned, accumulate and S variants; independent 64-bit edge products, wraparound, complete register results, NZ with CVQ preservation and input/output aliases in `test/isa/dsp.cpp` |
| SMULxy/SMLAxy/SMLALxy/SMULWy/SMLAWy | All bottom/top selections; signed halfword products, long accumulation, independently floor-rounded word-by-halfword products and sticky Q on overflow; K3 uses halfword multiplies |
| CLZ and QADD/QSUB/QDADD/QDSUB | Zero and signed extrema, independent clamp arithmetic, sticky Q from either double or final saturation; untouched NZCV |
| Classic Thumb ALU | Shifts, add/subtract, immediate MOV/CMP/ADD/SUB, all low-register logical/arithmetic/multiply forms and high-register operations normalize into the same reviewed operation semantics. Independent arithmetic oracle and shift boundary tables check flags and complete registers |
| Classic Thumb memory | Register/immediate byte, halfword, word and signed forms, SP-relative and PC-literal addressing, ADR and SP adjustment; both endiannesses and fixed/dynamic memory paths checked; PUSH/POP/LDM/STM ordering, base-in-list writeback suppression and POP PC interworking checked |
| Classic Thumb control | All conditional branches against independent NZCV truth masks, unconditional branches, BX/BLX and separate BL/BLX halves; IRQ and snapshot return between halves, ARM/Thumb exception entry/return, invalid pair/entry forms and out-of-profile extensions checked |
| SWI/UDF/BKPT | Precise vector/SPSR/LR/mask entry and return; explicit ARM UDF encoding and BKPT prefetch-abort fallback checked. Other unsupported encodings still refuse preparation |
| PLD | Advisory hint has no required observable data access; accepted without inventing faults or device reads |
| Invalid/unsupported encodings | Public preparation diagnostics cover extension collisions, ARMv6 media/exclusive/UMAAL/unconditional control, malformed control fields and invalid long-multiply pairs/PC and explicit unlowered CP15 |

Instruction encodings/semantics: ARM DDI 0100I A2–A7, restricted to ARMv5TEJ.
Profile: DDI 0198E. Nominal cycle accounting: DDI 0165B 8.1, without interlocks or
bus waits. References and their exact local identities are in
`reference-manifest.json`; manuals never enter production builds or tests.
